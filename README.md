# 广期所仓单日报 · 复刻版

一个与 [vaorrrr.github.io/gfex-cangdan](https://vaorrrr.github.io/gfex-cangdan/) 功能一致的仓单日报网站：展示广州期货交易所 **碳酸锂（LC）/ 多晶硅（PS）/ 工业硅（SI）** 的每日仓单注册、注销与净变化，含多年同期对比、分商标、分仓库、分省份/区域分析，**数据可直连广期所官网自动更新**。

## 目录结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 仓单日报主站（自包含单文件，已内嵌最新数据） |
| `admin.html` | 数据更新工具：录入 / 导入 JSON·CSV / 一键同步原站，导出新数据文件 |
| `update_gfex.py` | **官网自动抓取脚本**：直连广期所官网接口抓取最新仓单日报并更新全部数据文件 |
| `安装自动更新.bat` | 双击（管理员）注册“每天 07:45 自动更新”的 Windows 计划任务 |
| `手动更新.bat` | 双击立即从官网抓取一次最新数据 |
| `.github/workflows/update-gfex.yml` | GitHub Actions 定时任务：每天自动抓取并提交，GitHub Pages 站点零人工更新 |
| `data.json` | 最新一日完整快照（含汇总、仓库明细、历史序列、可用日期） |
| `days-2024.json` `days-2025.json` `days-2026.json` | 按年拆分的历史交易日明细（仓库级），驱动日期切换、季节图、分省/分区域历史折线 |
| `build.py` | 将最新 `data.json` 重新嵌入 `index.html`（双击打开也显示最新数据） |
| `update_log.txt` | 自动更新运行日志（由 update_gfex.py 生成） |
| `test_site.py` | 功能验证脚本（可选） |

## 本地预览

- **最快**：直接双击 `index.html`（内嵌最新数据，可看全部图表与明细；切换历史日期需用服务器方式）。
- **完整功能**：在目录下启动本地服务器后打开 `http://127.0.0.1:8931/index.html`：

  ```
  python -m http.server 8931
  ```

  服务器方式下会自动加载 `days-*.json`，可切换全部历史交易日、查看仓库季节图与省份/区域历史折线。

## 自动更新（核心功能：直连广期所官网）

`update_gfex.py` 直接调用广期所官网仓单日报接口，自动完成：探测最近已公布的交易日 → 抓取碳酸锂 / 多晶硅 / 工业硅三个品种明细 → 推断注册 / 注销 → 计算日 / 周 / 月变化（基准自动对齐最近可用交易日）→ 合并历史序列 → 写入 `data.json`、`days-YYYY.json` 并重建内嵌数据的 `index.html`。全程只用 Python 标准库，无任何第三方依赖。

### 方式一：本机计划任务（推荐，本机即可自动更新）

1. 双击 **`安装自动更新.bat`**（出现提示时选“以管理员身份运行”）。
2. 注册成功后，每天 **07:45**（官网公布仓单日报之后）自动抓取最新数据并更新本站文件。
3. 随时可双击 **`手动更新.bat`** 立即抓取一次。
4. 更新结果记录在 `update_log.txt`。

> 若网站托管在 GitHub Pages，本机更新后需把更新过的文件推送到仓库才会生效（或直接用下面的方式二，完全免人工）。

### 方式二：GitHub Actions 云端定时（托管在 GitHub Pages 时，完全免人工）

1. 把本项目（含 `.github/workflows/update-gfex.yml`）推送到你的 GitHub 仓库。
2. 在仓库 **Actions** 页面确认工作流「每日自动更新仓单数据」已启用。
3. 此后每天 07:45（北京时间）自动抓取官网数据并提交更新，Pages 站点自动刷新，无需任何人工操作。
4. 也可以在 Actions 页面手动触发（Run workflow）立即更新。

### 命令行用法

```
python update_gfex.py                  # 自动探测并抓取最新交易日
python update_gfex.py --date 20260921  # 抓取指定交易日（yyyyMMdd）
python update_gfex.py --dry-run        # 只探测与计算，不写文件
```

## 部署（让网站对外可访问）

任意静态托管均可，推荐 GitHub Pages：

1. 把 `index.html`、`admin.html`、`data.json`、`days-*.json`（如需云自动更新再加 `.github/` 与 `update_gfex.py`）上传到仓库（保持同一目录）。
2. 在仓库 Settings → Pages 中启用 GitHub Pages（选择分支/目录后保存）。
3. 访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

## 手动更新数据（备选）

> 除自动脚本外，也可打开 admin.html 手动录入 / 导入 / 从原站同步，生成新数据文件后覆盖部署。

### 方式一：一键同步原站（联网即可）

1. 打开 `admin.html`（本地服务器或线上均可）。
2. 点击 **「从原站一键同步最新数据」**——自动从原站拉取最新 `data.json` 与全部历史日数据。
3. 编辑当日数据（见方式三的编辑说明），点 **「计算并生成」**。
4. 点 **「下载 data.json」** 与 **「下载 days-YYYY.json」**，覆盖网站目录同名文件后重新部署。

### 方式二：导入

在 admin.html 的「从剪贴板导入」框粘贴以下任意一种，点「解析导入」：

- **当日 JSON**：`{"data_date":"2026-09-21","details":{"lc":[...],"ps":[...],"si":[...]}}`（与 data.json / days 文件同构，含 `warehouse / trademark / last / today / reg / logout` 字段）。
- **CSV 行**：每行 `品种,仓库,商标,今日仓单,注册量,注销量`（注册量/注销量可留空），品种可用 `lc / ps / si` 或中文名：

  ```
  lc,象屿速传上海,,4343,0,340
  ps,中物流（石河子）,东方希望,210,0,0
  si,中储吴淞,,108,0,0
  ```

- **历史日文件**：粘贴 `days-2026.json` 的内容，可整体并入历史库。

### 方式三：手动编辑

1. 载入数据后，在「数据日期」填新交易日（默认填今日），「今日仓单」已默认填为上一交易日数值，只需修改**有变化的行**。
2. 注册量 / 注销量留空时，程序按「今日 − 昨日」自动推断正负。
3. 周/月对比基准自动建议（上周同期 / 上月同期），可手动改。
4. 新品种、新仓库用「＋ 添加一行」。
5. 点 **「计算并生成」** → 核对汇总预览 → 下载两个 JSON 文件并部署。

- 库容口径：仓库为交易所公布的最低保障库容（非硬上限），厂库为标准仓单最大量；占用 = 该库仓单合计（吨）÷ 核定库容；碳酸锂 1 吨/手、多晶硅 3 吨/手、工业硅 5 吨/手。
- 自动脚本依赖官网接口，若官网改版导致接口变动，需相应更新 `update_gfex.py`。

## 常见问题

- **双击 index.html 无法切换历史日期 / 没有省分历史折线**：浏览器禁止 `file://` 页面读取本地 JSON，请用 `python -m http.server` 或部署后使用。
- **admin.html 在本地双击打不开**：同样请用本地服务器打开，或直接部署后在线操作。
- **更新后希望双击 index.html 也显示最新数据**：自动脚本已自动重建 index.html；手动改数据后执行 `python build.py` 即可。
- **官网当天数据几点出来**：仓单日报统计截至交易日 15:00，次日上午约 07:30 在官网公布，因此自动任务默认 07:45 运行。
